# Phase 0.5：交易脚本安全基线

更新时间：2026-08-21

## 结论

当前适合由 Codex 直接在本地工程内迭代，不适合先让 ChatGPT 生成一套大方案、再把 prompt 转交给另一个 Codex。原因是这次工作的主要难点不是写方案，而是核对真实文件、保留现有策略语义、逐步替换危险边界并做离线验证。

本轮参考工程为：

`D:\lh\trad_data_service_20260821\data_service`

采用了其中已经验证过的几类工程模式：本地环境文件、不可变设置、失败关闭、单写入锁、临时文件写完后原子替换。没有复制其业务逻辑，也没有改变预测模型本身。

## 已完成

1. 运行密钥从现用 Python 和监控脚本中移除，统一由 `.env.local` 或进程环境变量提供。
2. 默认 `BYBIT_TRADING_MODE=shadow`。影子模式把拟下订单记录在内存中，不导入 CCXT 私有交易客户端，也不调用 Bybit 私有下单接口。
3. `testnet` 和 `live` 都要求密钥；`live` 还必须额外设置 `BYBIT_ENABLE_LIVE=true`，否则启动立即失败。
4. Bybit 客户端延迟初始化。导入策略文件不再自动连接账户或加载市场。
5. 修正多币种预测读取错误：请求 `ETHUSDT` 时不会再固定读取 `XRPUSDT`。
6. 同时兼容旧 `/results/{symbol}` 和新 `/predict/{symbol}` 的预测结构。
7. 对预测增加失败关闭门槛：币种不匹配、趋势非法、时间缺失、时间过期、数据源异常或明确不可靠时，不进入交易判断。
8. 内网 HTTPS 默认校验证书；可通过 `PREDICTION_CA_BUNDLE` 指定内网 CA。确有需要时才可显式关闭校验。
9. `setting_v4.ini` 的更新改为同进程串行、同目录临时文件写入、刷新落盘后原子替换，降低中途退出造成半文件的风险。
10. 飞书 webhook 改为可选环境变量；未配置时只跳过通知，不影响主流程。
11. 监控脚本改为从自身目录启动，并读取 `.env.local`，不再依赖固定 Linux 绝对路径。

## 运行模式

| 模式 | 私有交易接口 | 密钥要求 | 额外开关 | 用途 |
|---|---:|---:|---:|---|
| `shadow` | 不调用 | 否 | 否 | 当前默认；先跑策略与接口联调 |
| `testnet` | Bybit 测试网 | 是 | 否 | 第二阶段真实接口联调 |
| `live` | Bybit 主网 | 是 | `BYBIT_ENABLE_LIVE=true` | 仅经人工批准后启用 |

## 本地配置

现用配置文件：`BybitContractBotV4/.env.local`。该文件已被 `.gitignore` 排除。

切换到内网预测服务时，只需修改：

```text
PREDICTION_API_BASE_URL=https://你的内网服务地址
PREDICTION_API_ROUTE=/results/{symbol}
PREDICTION_API_TOKEN=
PREDICTION_CA_BUNDLE=内网CA文件绝对路径
```

若部署的是新接口，把路由改为 `/predict/{symbol}`；交易端解析器同时支持两种响应。

## 验证结果

离线安全测试共 10 项，全部通过，包括：

- 默认影子模式且无需密钥；
- 主网缺少双重授权时拒绝启动；
- 测试网与主网缺少密钥时拒绝启动；
- 客户端导入与创建阶段不自动连接；
- 影子订单只进入内存；
- ETH 请求不会误读 XRP；
- 新旧预测结构均可解析；
- 过期或不可靠预测会被拒绝。

相关 Python 文件也已完成语法编译检查。

## 本地版本记录

Codex 的 Windows 沙箱账户与工程目录所有者不同，标准 `.git` 会触发 Git 的所有者保护。为避免影响后续工程操作，版本数据库保存在 `.version-history`，该目录不参与文件快照。

在 `D:\Money` 中可使用：

```powershell
.\git-local.ps1 status
.\git-local.ps1 log --oneline
.\git-local.ps1 diff
```

它仍是普通 Git 仓库，只是工作目录和版本数据库分开保存。

## 尚未完成的高风险项

这轮是可运行的安全基线，不是完整交易系统重构。以下仍应放在后续阶段：

3. 最大单笔风险、最大总敞口、日损失、连续失败和熔断规则。
4. 将可变运行状态从 `setting_v4.ini` 迁移到专门的状态存储。
5. 测试网端到端验收和少量主网灰度清单。

在这些项目完成前，建议保持 `shadow`；即使填入真实密钥，也不要提前切换 `live`。
